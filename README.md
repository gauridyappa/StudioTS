# StudioTS – Salon Management & Appointment Booking Website

StudioTS is a responsive salon management and appointment booking website designed to simplify salon service discovery, appointment scheduling, and customer interactions. The platform provides an intuitive interface for exploring salon services, viewing pricing, and managing booking requests.

## 🚀 Features

- **Responsive Website:** Mobile-friendly interface accessible across desktop, tablet, and mobile devices.
- **Service Management:** Browse salon services, categories, descriptions, and pricing.
- **Appointment Booking:** Interactive booking forms for submitting appointment requests.
- **Customer Interaction:** User-friendly forms for customer inquiries and communication.
- **Service Filtering:** Explore and filter salon services based on available categories.
- **Business Information:** Access salon details, services, and relevant information.
- **Dynamic UI:** Interactive components and form validation using JavaScript.

## ⚙️ How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/gauridyappa/StudioTS.git
   ```

2. Open the project folder:

   ```bash
   cd StudioTS
   ```

3. Open `index.html` in your browser.

4. Alternatively, use the **Live Server** extension in Visual Studio Code for local development.
